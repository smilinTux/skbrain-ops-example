# Contributing

- Branch from `main`, open a pull request, never push to `main`.
- One page per PR where practical. New pages start `lifecycle: draft`.
- Commit messages end with a `Co-Authored-By` trailer naming who actually did the work, only when true.
- The gate is `skbrain check --canon .`. Run it before pushing.
- The author of a PR never merges it. A reviewer from `reviewers` in `skbrain.yaml` approves.
